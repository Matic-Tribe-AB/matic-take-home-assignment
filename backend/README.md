# PostFeed Backend

Express API starter. See the root README for the full brief.

## Setup

```bash
npm install
npm start        # production
npm run dev      # watch mode (nodemon)
npm test         # run tests
```

Runs on **http://localhost:3001** by default.

## Notes

- `src/app.js` is the entry point — implement your routes here or split into separate route files
- Persistence is your choice: in-memory array, JSON file, or SQLite
- Add any dependencies you need via `npm install`
